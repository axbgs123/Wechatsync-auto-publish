# 微信公众号与百家号封面版式

后续封面只参考版式，画面内容必须根据当篇文章重新设计。

微信公众号和百家号发布前都必须提供封面。生成新封面前，先检查本项目
`test-assets/` 中是否已有与当篇文章主题一致、版式和尺寸可用的封面；满足条件时
直接复用，主题不一致或尺寸不适配时才重新生成。复用只针对同一篇或主题高度一致
的文章，不能为了省事使用内容不相符的画面。

- 左侧约 43% 为浅色留白和三段式大标题，右侧约 57% 为写实业务场景。
- 第一行深蓝色，第二行最大并使用橙色，第三行深蓝色。
- 整体使用蓝白企业风，可在底部加很淡的蓝色波浪或科技纹理。
- 标题要短、完整、无错字；除指定标题外不生成其他文字、字母、数字、标志或水印。
- 右侧人物、场景和流程图必须服务于当篇文章主题，不复制历史封面内容。
- 微信公众号默认输出 16:9。
- 百家号横版封面单独输出 3:2（1.5:1），不要把 16:9 成图机械居中裁切；
  必须重新排版，并在左右两侧保留安全边距。
